스크린 공간은 콘솔창 공간의 X좌표 2칸을 1칸으로 한다.
스크린 공간에 배경색을 칠해 픽셀 스타일 정사각형에 색을 입힐 수 있다.
월드의 크기는 스크린 공간의 1픽셀을 1칸이라 했을때 100*100 이다.
플레이어는 노란색 1픽셀로 화면에 표시한다. (플레이어는 항상 월드 위에 위치하고 있다)
플레이어는 부드러운 이동(getAsyncKeyState)를 이용해서 VK_UP등의 파라메터를 활용하여 방향키로 상하좌우 월드 안에서 움직일 수 있게 만든다.
스크린 공간을 카메라라고 할때 카메라의 1/3~2/3 지점까진 플레이어가 이동하되, 해당영역을 벗어나려 하면 카메라를 이동시켜 항상 해당 영역 안에 플레이어가 위치하도록 한다.
맵의 가장자리 에 도달했을때 카메라는 월드를 벗어나지 않아야하며, 따라서 이 경우에는 카메라의 가장자리까지 캐릭터를 이동시키는 예외법칙을 적용한다.
카메라 좌표(중앙점의 월드좌표기준), 캐릭터좌표1(카메라좌표 기준), 캐릭터 좌표2(월드좌표기준)를 화면 최하단에 출력한다.
콘솔창은 80 * 30 으로 세팅하며, 마지막 두줄은 글자만 표기하기에 지도를 그리지 말것.
가로세로 5픽셀 단위로 바둑판 모양의 회색 선을 긋는다.
